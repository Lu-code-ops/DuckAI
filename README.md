# DuckAI v0.6

**Hệ thống giám sát đàn vịt – bản thử nghiệm nội bộ**

DuckAI v0.6 hiện tập trung vào nền tảng camera: quản lý nhiều camera, RTSP, tự kết nối lại, nhật ký hệ thống, snapshot cảnh báo và điều khiển giám sát.

> **Soi gì đó bé 😏 Source code không nằm ở đây đâu.**

Repository phát hành này **không phân phối mã nguồn Python**. Bản thực thi được cung cấp để thử nghiệm và sử dụng theo sự cho phép của tác giả.

## Chạy thử

1. Tải file phát hành `DuckAI_v06_SHARE.zip`.
2. Giải nén.
3. Chạy `DuckAI_v06.exe`.
4. Windows SmartScreen có thể hiện cảnh báo với ứng dụng chưa ký số; chỉ tiếp tục nếu file đến từ nguồn bạn tin cậy.

## Dữ liệu cục bộ

DuckAI lưu dữ liệu runtime của người dùng trong thư mục dữ liệu cục bộ của Windows (`LocalAppData\DuckAI`), không kèm dữ liệu cá nhân của máy phát triển trong bản phát hành.

## Lưu ý

Đây là bản thử nghiệm v0.6. Phần AI nhận diện hành vi bệnh thật vẫn chưa được huấn luyện/tích hợp cho tới khi có dữ liệu vịt thật phù hợp.
